# Дизайн «Первый заказ»

Ориентир: премиальное финтех-приложение. Чёрный и белый, один зелёный акцент только для денег, статуса «Оплачено» и печати. Без градиентов, неона, эмодзи и мультяшных иллюстраций.
Чего здесь нет, не придумывать. Если не хватает решения, остановиться и спросить.

## Структура экрана
- Два слоя. Hero: всегда чёрный #000000, в нём заголовок экрана (28px) и круглые кнопки действий 40px с фоном rgba(255,255,255,0.10). Sheet: лист с радиусом сверху 32px, поднятый на 28px поверх hero.
- Колонка не шире 480px по центру, вокруг неё чёрный фон.
- Боковые поля экрана 20px. Нижний отступ контента: высота навигации + 24px + safe-area.

## Цвета (CSS-переменные на :root, тема через data-theme на html)
Тёмная:
  --hero #000000; --sheet #0D0D0D; --surface #141414; --field #1A1A1A
  --line rgba(255,255,255,0.08); --line-strong rgba(255,255,255,0.16)
  --text #F5F5F5; --text-2 #B4B4B4; --text-3 #8A8A8A
  --btn-bg #FFFFFF; --btn-text #000000
  --accent #7CC9B0; --danger #FF8A80
Светлая:
  --hero #000000; --sheet #FFFFFF; --surface #F6F6F6; --field #F2F2F2
  --line #E8E8E8; --line-strong #D4D4D4
  --text #0A0A0A; --text-2 #5C5C5C; --text-3 #737373
  --btn-bg #0A0A0A; --btn-text #FFFFFF
  --accent #1F6F5C; --danger #B3382C
Текст на hero всегда #F5F5F5, второстепенный #8A8A8A, в обеих темах.
Цвета только через переменные, hex внутри компонентов запрещены.
Старые переменные --color-* оставить алиасами на новые, пока не перенесены все экраны.

## Типографика
- Шрифт Manrope (пакет @fontsource-variable/manrope, подмножества latin, cyrillic, cyrillic-ext), запасной system-ui. Позже проверить буквы ү, ө, ң.
- Размер / высота строки / вес / межбуквенный:
  display 40/44/700/-0.03em (суммы)
  title 28/32/700/-0.02em (заголовок экрана)
  h2 20/26/600/-0.01em
  body 16/24/500/0
  small 14/20/500/0
  caption 12/16/500/0.02em
- Меньше 12px не использовать. Поля ввода всегда 16px (иначе iPhone приближает страницу).
- Деньги и числа: font-variant-numeric: tabular-nums. Формат через Intl.NumberFormat('ru-RU') и неразрывный пробел перед «сом»: «1 500 сом».

## Сетка и формы
- Шаг 4px. Промежутки между блоками 12, 16, 24.
- Кнопки: pill (999px), высота 52. Поля: радиус 14, высота 52. Карточки: радиус 20, отступы 16–20. Чипы: pill, высота 36.
- Тени в тёмной теме запрещены. Слои различаются поверхностями и линией 1px --line. Единственная тень: у плавающей навигации в светлой теме, 0 8px 24px rgba(0,0,0,0.18).

## Компоненты
- Button primary: фон --btn-bg, текст --btn-text, 16/600. Secondary: прозрачный, рамка 1px --line-strong. Ghost: без рамки.
- Состояния кнопки: hover (только @media (hover:hover)) осветляет фон на 6%; active scale(0.97); focus-visible кольцо 2px --text с отступом 2px; disabled opacity 0.4.
- Loading кнопки: вместо текста три пульсирующие точки, ширина кнопки не меняется.
- Input: подпись над полем (caption, --text-3), фон --field, без рамки в покое, при фокусе рамка 1px --text (160ms). Ошибка: под полем 13px --danger, выезжает вниз, поле обводится --danger.
- Segmented control: фон --field, радиус 14, ползунок едет под выбранный пункт.
- Chip: выбранный инвертирован (фон --text, текст --sheet).
- Card: --surface, радиус 20, рамка 1px --line.
- Badge: pill высотой 24, 12/600. «Оплачено» цвета --accent на подложке accent 14%, остальные нейтральные.
- Нижняя навигация: плавающая таблетка по центру, bottom 16px + safe-area, высота 64, padding 6. Тёмная тема: фон #1A1A1A и рамка --line-strong. Светлая: фон #000000. Четыре иконки Lucide 22px, stroke 1.75. Активный пункт: белый круг 52px с чёрной иконкой, круг переезжает между пунктами. Подписей нет, у каждой иконки aria-label. При фокусе на поле ввода на экранах уже 768px таблетка уезжает вниз и возвращается при blur.
- Skeleton: вместо слова «Загрузка» блоки формы будущего контента, мерцание 1.4s linear infinite.
- Empty state: иконка 40px в круге 72px, заголовок h2, одна строка пояснения, одна кнопка действия.
- Toast: сверху, pill, выезжает за 220ms, живёт 2.6s.

## Движение
Принцип: плавно там, где пользователь смотрит, резко там, где он нажимает.
Токены:
  --ease-out cubic-bezier(0.22, 1, 0.36, 1)       плавные появления
  --ease-in-out cubic-bezier(0.65, 0, 0.35, 1)    переходы экранов
  --ease-snap cubic-bezier(0.2, 0.9, 0.25, 1)     резкие реакции
  --dur-press 90ms; --dur-fast 160ms; --dur-base 260ms; --dur-slow 420ms
Правила:
1. Нажатие: scale(0.97) за 90ms ease-snap, отпускание 160ms ease-out.
2. Новый экран: opacity 0 к 1 и translateY 12px к 0, 260ms ease-out. Старый без анимации.
3. Sheet при открытии экрана: поднимается на 24px и проявляется, 420ms ease-out.
4. Списки: элементы появляются по очереди с задержкой 40ms, не больше 6 элементов, дальше без задержки.
5. Индикатор навигации: spring, stiffness 520, damping 40, без раскачки.
6. Числа (заработок): счёт от старого значения к новому, 700ms ease-out, только при изменении.Это исключение из предела 450ms.
7. Печать при получении: scale 1.7 к 1, rotate -24° к -10°, opacity 0 к 1, 340ms ease-snap с лёгким перелётом (scale 0.95 перед 1). Одновременно sheet вздрагивает: translateY 3px к 0, 140ms. Это единственная выразительная анимация, остальные сдержанные.
8. Ошибка поля: горизонтальная тряска 3 колебания по 4px за 220ms, один раз.
9. Смена темы: background-color, color, border-color за 200ms на корневых контейнерах, не на *.
10. Анимировать только transform и opacity. Исключение: высота блока ошибки через grid-template-rows 0fr к 1fr.
11. prefers-reduced-motion: reduce убирает перемещения и масштаб, остаётся fade 120ms, печать появляется без поворота.
Библиотека для spring и layout-анимаций: motion (импорт из "motion/react"). Остальное на CSS.

## Нельзя
Градиенты (кроме Skeleton), тени в тёмной теме, эмодзи, рамки толще 1px, \переходы и однократные анимации движения длиннее 450ms (счёт чисел до 700ms и зацикленные анимации Skeleton и loading этим пределом не ограничены), цвета вне токенов, иконки не из Lucide, новые зависимости без согласования (разрешены только motion и шрифт).

## Приёмка каждого шага
Обе темы читаются. В компонентах нет hex-цветов. Все состояния кнопок и полей работают. Есть prefers-reduced-motion. npm run build без ошибок.
