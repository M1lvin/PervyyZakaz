# Первый заказ

Сервис, где местные малые бизнесы публикуют небольшие задачи, а студенты откликаются,
набирают первые проекты и отзывы.

## Пользователи
- Студент: ищет заказы, откликается, сдаёт работу.
- Бизнес: публикует задачу, принимает работу, отмечает оплату.

## Функции первой версии
1. Лента открытых заказов с фильтром по навыку.
2. Публикация заказа: название бизнеса, задача, описание, бюджет, срок, навык.
3. Отклик студента: цена, срок, сообщение.
4. Статусы: открыт → в работе → сдано → оплачено.
5. Раздел «Мои заказы» для студента и бизнеса.
6. Профиль студента: имя, контакт, навыки, заработок за оплаченные заказы.
7. Печать «Первый заказ» после первого оплаченного заказа.
8. AI: текст отклика и подсказка цены (через серверную функцию, ключ не в браузере).

## Не делаем в первой версии
Платежи в приложении, чат, рейтинги, уведомления, кыргызский язык.

## Требования
- Работает на телефоне и на компьютере (сначала телефон).
- Русский язык, короткие подписи.
- Ошибки ввода показываются под полем и не ломают приложение.
- Данные сохраняются после перезагрузки.

## Технический стек
React + Vite + TypeScript, Tailwind CSS. Позже: Supabase (база, вход) и серверная функция для AI.
